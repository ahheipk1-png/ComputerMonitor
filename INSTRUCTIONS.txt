=======================================================
   ComputerMonitor - Remote Telemetry Agent Setup
=======================================================

Thank you for downloading ComputerMonitor Agent!
This package lets you monitor this computer from your web dashboard:
https://computermonitor.pages.dev

-------------------------------------------------------
QUICK SETUP (WINDOWS)
-------------------------------------------------------

METHOD 1: Automatic Startup (Recommended)
1. Right-click 'install-startup-task.bat' and run it (or double-click).
2. This registers the silent background agent in Windows Task Scheduler.
3. The agent will run completely silently in the background (0% CPU, no terminal window) and automatically start whenever Windows boots!

METHOD 2: Quick Manual Start
1. Double-click 'start-agent.bat' or 'ComputerMonitorAgent.exe'.
2. The agent starts on port 5500.

METHOD 3: Desktop Control Panel GUI
1. Double-click 'ComputerMonitorControl.exe'.
2. You can Start/Stop the agent, install/remove the startup task, and view live status with 1 click.

-------------------------------------------------------
CONNECTING TO YOUR WEB DASHBOARD
-------------------------------------------------------
1. Open https://computermonitor.pages.dev in any web browser (on your phone, tablet, or another PC).
2. Click the '+ Add Computer' button at the top of the dashboard.
3. Enter:
   - Computer Name: (e.g. My Laptop, Living Room PC, Server)
   - Agent Endpoint URL: http://<THIS_COMPUTER_IP>:5500
     (To find this computer's IP, open Command Prompt and type 'ipconfig', e.g. 192.168.1.50)
4. Click 'Add Computer' - live metrics, CPU, Memory, and processes will instantly stream!

-------------------------------------------------------
HOW TO STOP OR REMOVE
-------------------------------------------------------
- To stop the agent: double-click 'stop-agent.bat' or use 'ComputerMonitorControl.exe'.
- To remove the Windows startup task: double-click 'uninstall-startup-task.bat'.
